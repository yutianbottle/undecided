# UI 优化落实与验证 · 2026-11-04

依据《UI诊断-2026-11-04.md》的优先级建议实施，保留深灰底、纸白、暖金、宋体问句、等高线与环境光。

| 诊断项 | 本次落实 |
| --- | --- |
| P0：信息文字过淡、11px 小字 | 分类标签、语言切换、保存状态等统一不低于 12px；信息文字至少使用 `--paper-56`。未选语言项实测为 `#97938E`，底色 `#111318`，对比度约 6.1:1。 |
| P1：三套流程进度叠加 | 案卷页仅保留无刻度细线与当前位置；移除数字计数和七项步骤导航。台面草稿状态改为当前位置名称，封存与回看页也不再显示步骤计数。 |
| P1：地形图同簇重叠 | 同簇点作小幅偏移，标签用引线分开；按容器宽度绘制，移动端不再要求横滑；320px 下另外调整英文标签位置。用户案卷金环跟随相同偏移。 |
| P2：品牌与新建入口重复 | 导航左侧使用纸张标记；统一中英文新建入口文案，移除空态底部的重复入口。 |
| P2：天数使用冷蓝 | 天数与一般状态改为暖灰；「现在就能回看」使用暖金。 |
| 字号系统漂移 | HTML 界面文字收敛为页标题、段标题、条目、正文、说明、标签六种语义 token；说明文字统一主要行距。 |
| 移动端辅助操作挤入底栏 | 底栏只保留台面、账本、我；语言与源码入口移至页脚，扩大触控尺寸。地形图在移动端也位于关口列表之前。 |
| 落槌前缺少回顾与退路 | 落槌表单直接显示事实、具体处境、反证和换位答案；停顿页显示选择、预测、概率、回看日期，并可返回修改。 |
| 其他视觉细节 | 调整标题字距、列表行间距、空账本入口提示、保存异常横幅，以及日期、下拉、概率滑块的样式。 |

## 验证

- `npm run build`：通过。
- `npm test`：6 个文件、150 项测试通过。
- `git diff --check`：通过。
- 浏览器检查桌面 1280×800、移动端 390×844、最窄 320×740；中英文地图标签边界检查无重叠，页面无横向溢出。
- 浏览器走通新建 → 选项 → 事实 → 换位 → 照明 → 落槌表单 → 停顿摘要 → 返回修改；事实和答案可见，返回后保留选择与预测，原计时器不会再次触发。
- 用独立 `localhost` 地址的「UI 验证」草稿验证流程，交付预览使用 `127.0.0.1`。

以上为构建、现有测试与浏览器验证结果，未重新运行诊断文档中的 Impeccable 评分，不推算新的分数。
